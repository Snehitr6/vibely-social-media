# Vibely – Social Media Platform

Vibely is a modern, responsive social media web application built using React.js, Vite, and Tailwind CSS. It allows users to connect, share posts, explore content, watch short videos, and interact with other users through a clean and user-friendly interface.

## 🚀 Features

- **User Authentication** – Login and signup functionality.
- **Home Feed** – View posts and updates from users.
- **Stories** – Create, view, and manage stories.
- **Create Posts** – Share content with captions.
- **Like & Comment** – Interact with posts.
- **Explore Page** – Discover new content.
- **Reels** – Watch short videos, like, comment, and share.
- **Messages** – Messaging interface.
- **Notifications** – View activity notifications.
- **User Profiles** – View and update profile information.
- **Follow System** – Follow and unfollow users.
- **Save Posts** – Bookmark posts for later.
- **Responsive Design** – Optimized for desktop, tablet, and mobile devices.
- **Local Storage** – Save demo application data in the browser.

## 🛠️ Technologies Used

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- React Router DOM
- Lucide React Icons
- HTML5
- CSS3
- Local Storage
